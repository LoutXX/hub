Privacy Policy

Last updated: October 7, 2026

Overview

Skorozvon Hub ("the app") is a private tool operated by its owner for personal business use. This policy explains what Google user data the app accesses and how it is used.

Google user data the app accesses

  • Google Drive: the app uploads call-recording files (MP3) into one Drive folder designated by the account owner, and sets a "anyone with the link can view" permission on the files it uploads. The app does not browse, read, change or delete other files in the account.
  • Account authorization: the app stores an OAuth refresh token for the authorizing account on the owner's own server, solely to be able to upload files without asking for sign-in each time.

How the data is used

The data is used only to provide the feature described above: storing call recordings in the owner's Google Drive. It is not used for advertising, profiling or any other purpose.

Sharing

Google user data is not sold, shared with, or transferred to third parties. Links to uploaded recordings are written to a spreadsheet owned by the same account owner.

Storage and security

The OAuth refresh token is stored in a configuration file on the owner's private server, accessible only to the owner. The app does not keep a copy of Google Drive contents.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The account owner can revoke the app's access at any time at myaccount.google.com/permissions. Revoking access invalidates the stored token. Files already uploaded can be deleted from Google Drive by the owner.
